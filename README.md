# 🌍 Smart Tourist Monitoring 2.0

A web-based tourist assistance platform designed to help users explore destinations, book tickets, access hotel information, and find important travel safety features.

## ✨ Features

* 🏛️ **Tourist Destinations:** Explore popular tourist places.
* 🎟️ **Ticket Booking:** Book tickets for tourist destinations.
* 🏨 **Hotel Enquiries:** Submit hotel booking enquiries and check their status.
* 👤 **User Authentication:** Register and log in.
* 🛡️ **Booking Verification:** Verify ticket bookings using a booking reference.
* 🚨 **Emergency Assistance:** Access emergency-related information.
* 📝 **Complaint Form:** Submit complaints.
* 📋 **Admin Dashboard:** View hotel enquiries and update their status.
* 📱 **Responsive Interface:** Browse the website on different screen sizes.
